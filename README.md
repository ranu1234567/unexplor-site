# Unexplor DMC Website (Node + Express, SEO-ready)
Run: `npm install && npm start` → http://localhost:3000   | Production: set `SITE_URL=https://yourdomain.com`
Edit contact/social/packages/blog in `data.js`. Enquiries save to `enquiries.jsonl`.
Built-in SEO: unique title/description/canonical per page, Open Graph, JSON-LD (TravelAgency, TouristTrip, BlogPosting, Breadcrumb, WebSite), sitemap.xml, robots.txt, internal links everywhere.

## External backlinks (manual – submit your site here)
Google Business Profile, Bing Places, TripAdvisor, Justdial, Sulekha, IndiaMART, UP Tourism / MoT registration pages, IATO/TAAI/ABTO-style associations, Facebook/Instagram/YouTube/LinkedIn bios, travel blog guest posts, Nepal tourism directories. Then add the social URLs in `data.js` (`site.social`).
